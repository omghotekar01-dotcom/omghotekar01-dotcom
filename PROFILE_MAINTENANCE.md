# Profile README maintenance

This is the special GitHub profile repository for **omghotekar01-dotcom**. Its root README is displayed on the GitHub profile.

## Structure

- `README.md` — public profile narrative and links.
- `assets/hero.svg` — original static banner designed for the README.
- `assets/projects/` — original illustrated cards, linked to public projects.
- `assets/activity.svg` — public GitHub metrics and contribution calendar; refreshed by the workflow.
- `assets/github-snake.svg` — contribution snake, generated by Platane/snk when the Action succeeds.
- `scripts/render_profile.py` — stdlib-only stats renderer. Only public GitHub repository data is shown.
- `.github/workflows/profile-activity.yml` — daily refresh + manual trigger + README change trigger.

## Verification & operation

Open **Actions > Refresh GitHub profile activity** and choose **Run workflow** to force regeneration. The workflow is also scheduled daily; changes committed with the automatic GitHub token do not trigger a new push build.

If a stats service or GitHub API is unavailable, the local SVG visuals remain available. GitHub's **own** contributions calendar on the profile is authoritative. Third-party rendering and scheduled actions are best effort.

The project cards are **curated** and are not automatically reordered when new repositories are added. Keep descriptions accurate and check source READMEs before making production or performance claims. Do not put personal credentials or private source information into this public repository.
